RFC 9530 Digest Fields & API Request Signing Standard

Why modern payment webhooks and multi-tenant gateways standardize body integrity headers using Content-Digest and Repr-Digest.

Primary Specification Source
https://www.rfc-editor.org/rfc/rfc9530.html
Open Reference

Editorial Takeaways for Webhook Receivers

  • Separates transport-encoding checksums (Content-Digest) from representation checksums (Repr-Digest).
  • Replaces deprecated MD5 header conventions with explicit algorithm negotiation (sha-256 / sha-512).
  • Pairs directly with RFC 9421 HTTP Message Signatures to defeat replay and payload truncation attacks.
